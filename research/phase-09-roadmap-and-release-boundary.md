# Phase 09: Roadmap and Release Boundary

## Goal

Draw a clear boundary between completed infrastructure, demonstration experiments, future validated studies, and unsupported claims.

## Roadmap Categories

Use these categories in research documentation and release notes:

- Complete infrastructure.
- Demonstration experiments.
- Future validated studies.
- Unsupported claims.

## Near-Term Research Milestones

1. Strategy-based retrieval with semantic parity.
2. Synthetic benchmark and dataset validator.
3. Experiment runner with core retrieval metrics.
4. Reproducible artifact persistence.
5. Private research dashboard.
6. First temporal retrieval engineering-validation run.
7. Larger consented benchmark design.
8. Temporal, hierarchical, graph-based, and personalized retrieval studies.

## Release Boundary

Before treating the research platform as complete, confirm:

- Normal Memory search still works.
- Retrieval is strategy-based rather than hard-coded.
- Initial retrieval strategies are implemented.
- A synthetic versioned benchmark exists.
- Experiments can be configured and run from the command line.
- Standard retrieval metrics are computed correctly.
- Run artifacts are persisted.
- Results can be inspected in a research dashboard.
- Privacy boundaries remain intact.
- Tests, linting, type checks, and documentation checks pass.
- The initial demonstration experiment runs end-to-end.
- Every major feature has a focused commit.

## Final Handoff Contents

At the end of implementation, provide:

- Architecture summary.
- Changed files.
- Validation commands.
- Generated demonstration run ID.
- Unresolved limitations.
- Next smallest research milestone.
